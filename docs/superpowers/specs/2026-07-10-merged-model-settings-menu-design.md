# 合并模型设置菜单设计

## 目标

将顶层“添加模型路由”和“模型映射”合并为“模型设置”，减少模型池自动路由与手动路由入口造成的重复感。

## 菜单

“供应商与模型”仅保留：添加供应商 Key、管理供应商 Key、模型池、模型设置、Key 运行态。

选择本地模型后，“模型设置”提供：别名、路由模式、路由目标、添加路由目标、删除模型。

## 行为

- 路由目标复用现有 target 管理逻辑。
- 添加路由目标固定添加到当前选中的本地模型，不再重复询问本地模型 ID。
- 删除模型删除本地模型配置；若统一模型指向它，则切换到其他可用模型或清除统一模型。
- 配置结构和运行时路由保持不变。
